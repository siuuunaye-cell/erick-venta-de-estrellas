# ERICK VENTA DE ⭐

Standalone Flask project for Render. This is a new project; it does not modify the existing Cineflix service.

## Deploy on Render
1. Create a NEW GitHub repository, e.g. `erick-venta-de-estrellas`.
2. Upload the contents of this folder to the repository root. Keep `app.py`, `requirements.txt`, `Procfile`, `render.yaml`, and folders `templates/` and `static/` at the root.
3. In Render choose New + > Web Service and connect the new repository.
4. Build command: `pip install -r requirements.txt`
5. Start command: `gunicorn app:app`
6. Add environment variable `ADMIN_PASSWORD` with a strong unique password. `SECRET_KEY` should be generated by Render.

## Important
- This site records order requests; it does not take or verify payments. Do not mark an order paid until you verify payment independently.
- On Render free instances, the local SQLite database may not persist across redeploys/restarts. For production, use a persistent disk or managed database (e.g. PostgreSQL).
- Only advertise packages and services you can actually deliver, and comply with the game's terms.
